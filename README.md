# Caption Book

A responsive Bengali caption web app with categories, search, copy buttons, and locally saved custom captions.

## Publish free with GitHub Pages
1. Upload `index.html`, `manifest.json`, `sw.js`, and `icon.svg` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Wait for GitHub Pages to publish your site.

## Android
This is a web app/PWA. Once deployed over HTTPS, open it in Chrome on Android and use **⋮ → Add to Home screen** (wording can vary) to install it like an app.
For a standalone APK, a separate Android wrapper/build step is required; APK creation and signing options vary by service. Local custom captions are stored only in that browser/device and are not synced.
